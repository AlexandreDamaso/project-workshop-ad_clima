# project-workshop-ad_clima
Realiza busca de dados climáticos através do nome da cidade desejada.

## Deploy

O workflow do GitHub Actions compila e publica o site no GitHub Pages a cada
push para a branch `main`. Também é possível iniciar a publicação manualmente
pela aba **Actions**.

Na primeira publicação, configure **Settings > Pages > Build and deployment >
Source** como **GitHub Actions**. Após o deploy, o site ficará disponível em
https://alexandredamaso.github.io/project-workshop-ad_clima/.
